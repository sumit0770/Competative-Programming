# Codeforces Workspace Instructions

- Treat each solution file as a standalone competitive-programming submission.
- Avoid speculative code completion; only write code after checking the target file and the local pattern around it.
- Keep edits minimal and local to the file or problem being worked on.
- Do not introduce extra abstractions, shared helpers, or cross-file refactors unless explicitly requested.
- Ignore generated binaries, dSYM folders, and other local build artifacts.
- When validation is needed, compile only the touched C++ file with the existing workspace build task or the equivalent clang++ command.
